# Assumptions register

This register lists assumptions made while reconstructing the retrospective ADRs in [`adr/`](adr/README.md) on 2026-11-27 from commit `baa8eb2`. Each one is an inference, or a code-vs-docs observation, that the evidence does not settle. Change the Status column as items are confirmed or refuted. The original port's own assumptions live in `PORT_PLAN.md` § Assumptions and are not duplicated here.
